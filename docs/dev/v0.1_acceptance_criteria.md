# v0.1 acceptance criteria (confirmatory comparisons)

**Status:** revised per the external-validation decision report (26 Nov 2026),
draft for final sign-off. Values the report fixes are **locked** here (C3 numerical
tolerance; C4 metrics and correspondence rule; C5 metric family; the diagnostic/
blocking roles). The C1 margin is **not** a single number — it is selected by a
bounded pilot rule (below). No pilot or confirmatory benchmark is run until this
file and the preregistration are signed off and committed. This document
operationalises §4 of `v0.1_external_validation_preregistration.md`; the pilot/
held-out protocol, environment record, scorecards and waiver rule live there.

## Preregistration discipline (pilot vs held-out)

Tolerances/behaviour are estimated on a **pilot** fixture used only for that
purpose; its results are **not** part of any confirmatory claim. After the pilot
and sign-off, criteria are **locked**, then the confirmatory comparison runs as a
single sealed execution of a **held-out** set (which may contain many
predetermined spectra and Poisson realisations — "run once" means one execution of
the sealed set, not one spectrum). See the preregistration doc for the full sealed
protocol (generator spec, scenario grid, seeds/hashes, split, metric code,
margin-selection rule) that must be committed **before any number is produced**.

## Reference-evidence tiers (govern C4/C5 blocking)

- **Tier A** — phase presence/absence or spatial label supported by an
  **independent analytical method** (e.g. EPMA, co-registered independent map).
  Only Tier A errors can directly block release under C4/C5.
- **Tier B** — expert phase-reference interpretation with documented contextual
  evidence. **Diagnostic until adjudicated.**
- **Tier C** — inference from the same-suite reference library or from AXIOMM's own
  result. **Not independent validation.**

## Field definitions

Each comparison specifies: **what is measured**, the **comparator/reference**, the
**error metric and denominator**, the **zero / near-zero treatment**, the
**threshold** (with status), the **justification**, and whether a failure is
**release-blocking (P0/P1)** or **diagnostic only**.

### C1 — Net line intensities on synthetic spectra  *(revise; pilot-selected margin)*

- **Primary reference: the synthetic truth** — the known injected area of every
  component, generated independently of AXIOMM, PyMca and PyXRF. PyMca's fitted
  net is a **secondary, differential** cross-check, **not** the reference.
- **Measured:** each estimator (AXIOMM; PyMca) compared **separately with truth**,
  on the *same physical quantity* — either the same individual line, or the same
  **explicitly defined** sum of a line family (a principal-line ROI, a whole line
  family and a fitted component area are not interchangeable).
- **Primary metrics (vs truth):** signed truth-relative bias and absolute
  truth-relative error for positive, adequately-supported lines; RMSE (or
  equivalent dispersion) across repeated Poisson realisations; detection /
  false-detection outcomes for zero and near-zero lines.
- **Secondary (AXIOMM vs PyMca):** symmetric percentage difference **or** log ratio
  for positive values (never PyMca-as-denominator when truth is available).
  Diagnostic only.
- **Zero / near-zero:** **do not** use a single `k·√(background)` / `m·√(gross)`
  rule (not a method-independent variance model). Use the generator's repeated
  Poisson realisations to report false-detection rate, missed-detection rate,
  recovered-net-area distributions, and whether AXIOMM's observation state is
  correct. No new analytical LOD/LOQ claim is introduced.
- **Threshold — LOCKED (26 Nov 2026 sign-off): ±5%** on the mean signed
  truth-relative error in each preregistered high-signal stratum (the agreed 95% CI
  rule). Selected by the sealed pilot (commit `2e62a95`): the smallest of the
  predeclared candidates {5%, 10%} whose band contains every high-signal stratum's
  whole 95% CI — comfortably, since the observed bias is <0.02% (CIs within ±0.13%).
  The held-out set is judged against ±5%; the margin is not widened after seeing
  held-out data. The sealed scenario grid is kept as-is.
- **Blocking:** a reproducible **systematic error relative to synthetic truth**
  outside the locked margin → potentially **P1** (governed by the preregistered
  repeated-simulation summary, not one noisy realisation). A PyMca disagreement
  that follows from a declared quantity/background/peak-model difference is **not**
  P1.

### C2 — Behaviour under overlaps, missing lines, zero signal  *(approved as written)*

- **Measured:** on designed cases — two lines within detector resolution; a
  reference line with no signal; a flat zero-signal window — whether AXIOMM flags
  the overlap, abstains / marks `measured_zero` / `not_measured`, and never reports
  a net above its declared detection policy where there is no peak.
- **Comparator:** the known synthetic truth; PyMca (or PyXRF) for the
  overlap-resolved case.
- **Metric:** binary pass/fail per designed case. Confirmatory conditions: 100%
  correct observation-state semantics; no positive where true signal is zero; no
  claim of resolving an overlap AXIOMM's own policy declares unresolved; no-measure
  reasons stay distinguishable after save/load and reporting.
- **Note:** a parametric fitter (PyMca/PyXRF) separating an overlap AXIOMM's ROI
  refuses is **not** an AXIOMM failure — the v0.1 claim is honest abstention, not
  universal deconvolution.
- **Blocking:** fabricating signal, suppressing a true no-measurement reason, or
  representing unavailable evidence as observed → **P1**. Conservative abstention →
  acceptable.

### C3 — Cliff–Lorimer arithmetic  *(numerical equivalence; locked)*

- **Measured:** named Si-referenced cation ratios (**Ca/Si, Fe/Si, Mg/Si, Al/Si**
  when both elements are `measured_positive` above floor) **plus** preregistered
  positive intensity/k-factor vectors spanning the expected dynamic range, computed
  by AXIOMM vs independent implementations of the **same** operation (same net
  intensities, k-factors and convention, element order, reference convention,
  atomic weights/mass→molar, no absorption correction, same closure).
- **Oracle hierarchy:** (1) an explicit **hand-derived / minimal-NumPy** oracle
  (primary); (2) **eXSpy** (`exspy.utils.eds.quantification_cliff_lorimer`) as the
  independent software cross-check; (3) AXIOMM under test. Before the held-out run,
  verify factor orientation with a two-element analytic example whose expected
  ratio is written into the preregistration.
- **Metric:** **numerical equivalence** in float64 — **`rtol = 1e-10`,
  `atol = 1e-12`** on the compared fractions/ratios; eXSpy agreement within its own
  numerical noise. This is one mathematical operation: no experimental or model
  uncertainty, so percentage tolerance would hide reversed-convention, ordering,
  weight/atomic or missing-conversion errors.
- **Zero / near-zero:** ratios involving a zero/unavailable element are undefined
  and must **not** be forced to zero.
- **Blocking:** any unexplained failure at the locked numerical tolerance → **P1**.
- **Companion (diagnostic only):** AXIOMM's uncorrected wt% vs PyMca's
  matrix-corrected quant — a model comparison, never C3, never pass/fail.

### C4 — Map-level spatial agreement  *(Dice-primary; gated + diagnostic for v0.1)*

- **Measured:** overlap between AXIOMM phase/cluster domains and an **independent
  spatial phase reference** (Tier A: imaging / EPMA map), after a fixed label
  correspondence.
- **Metric:** per-phase **Dice** (primary) and **IoU** (secondary); a macro-average
  over phases present in the reference; an area-weighted aggregate reported
  separately; explicit handling of empty/absent phases. (No universal 0.8-style
  threshold — Dice/IoU depend on domain size, cropping, class imbalance, boundary
  and reference variability.)
- **Correspondence:** direct **semantic** mapping where AXIOMM emits phase names;
  for arbitrary cluster IDs, learn the mapping on a **pilot region and freeze it**.
  **Do not** run Hungarian assignment on the held-out map (it optimises the
  correspondence on confirmatory outcomes and inflates agreement).
- **Threshold:** **not signed off until an independent spatial reference exists**;
  any eventual criterion must account for co-registration uncertainty, reference
  pixel size/PSF, AXIOMM resolution, minimum domain size, boundary ambiguity and
  inter-annotator agreement.
- **Status/blocking:** **GATED** (no independent spatial reference currently) and
  **diagnostic for v0.1**. A low Dice alone is not P1; a reproducible software
  error that systematically displaces domains and changes the interpretation may
  independently meet the P1 definition.

### C5 — Abstention & false mineral identifications  *(metric family corrected)*

The earlier "false-positive rate = false confident labels / all confident labels"
is a **false-discovery proportion (FDP)**, not a conventional FPR. Report, at least:

1. **cluster-level FDP** — false confident phase labels ÷ all confident labels;
2. **area-weighted FDP** — pixels with false confident labels ÷ all confidently
   labelled pixels;
3. **coverage** — confidently labelled clusters/area ÷ all eligible clusters/area;
4. **abstention rate** — `unresolved` clusters/area ÷ all eligible clusters/area;
5. **selective risk** (only with per-cluster/domain reference labels) — error rate
   among non-abstained decisions.

- **Risk and coverage are reported together** (a classifier can get low conditional
  error by abstaining on nearly everything); risk–coverage is the right framework
  for an abstention-capable system.
- A *confident* label = a committed decision (species or family level), not
  `unresolved`. **Negatives** (for FDP): phases **absent** from the known assemblage.
- **Comparator:** per the tier hierarchy above. **Acceptance under Tier A
  evidence:** require **zero adjudicated** confident labels of phases known to be
  absent; report the **exact binomial** confidence interval for the observed count
  (for 0 events in `n` opportunities, ≈`3/n` is the familiar upper 95% bound, but
  report the exact interval); report the number of evaluated confident decisions
  and the labelled area. Zero observed events is **not** proof the rate is zero.
- **Threshold:** **do not** lock an arbitrary 5/10/15% before the reference quality
  and evaluation sample size are known.
- **Blocking:** a single false confident label is **P1 only** when the **absence
  evidence is Tier A** and the label changes the scientific interpretation.
  Weak-reference (Tier B) or reference-circular (Tier C) disagreements are
  **diagnostic until adjudicated**.

### C6 — Reproducibility (save/load + reruns)  *(approved)*

- **Measured:** identity of results and provenance across save/load and fixed-seed
  reruns. **Comparator:** AXIOMM itself. **Metric:** exact equality within float
  epsilon. **Threshold:** exact. **Blocking:** any non-reproducibility → **P1**.

### C7 — Runtime & memory  *(descriptive)*

- **Measured:** wall-clock and peak RSS on representative datasets. **Metric:**
  documented numbers, no pass/fail. **Blocking:** diagnostic, except failure
  (OOM/crash) of the **declared primary workflow** → **P0**.

### C8 — Provenance completeness & correctness  *(approved)*

- **Measured:** required provenance present and faithful after save/load (run
  config; per-element `source_energy_kev` + `reference_energy_kev`;
  `cross_energy_scale`/`cross_energy_status`; reliability `counting_basis`; policy
  name + version; software/reference versions; diagnostics). **Metric:** checklist
  complete and round-trip faithful. **Blocking:** missing/false provenance that
  prevents reproduction → **P1**; cosmetic gaps → diagnostic.

## Release-role summary

| Comparison | Decision | Release role |
|---|---|---|
| C1 net line intensities | revise; margin pilot-selected (no generic 10% yet) | blocking only for systematic error vs synthetic truth |
| C2 overlaps / missing / zero | approved substantially as written | **P1** if AXIOMM fabricates or suppresses evidence |
| C3 Cliff–Lorimer arithmetic | approved, tight numerical tolerance | **P1** on any unexplained arithmetic failure |
| C4 spatial agreement | approved metrics; **gated + diagnostic** for v0.1 | not blocking without an independent spatial reference |
| C5 abstention / false IDs | revise metric family (FDP + coverage + risk) | blocking only with Tier A reference evidence |
| C6 reproducibility | approved | **P1** on reproducibility failure |
| C7 runtime & memory | approved (descriptive) | **P0** only for primary-workflow failure |
| C8 provenance | approved | **P1** where missing/false provenance prevents reproduction |

## What can run now vs what is gated

- **Runs now (synthetic + software-differential):** C1, C2, C3, C6, C7, C8 — no
  real sample or standards needed.
- **Gated on Tier A references:** C4 (independent spatial reference / EPMA map) and
  confirmatory C5 (independent phase-level adjudication). Their absence limits the
  phase-accuracy and quantitative claims but does **not** block the ungated work or
  the narrower reproducibility/provenance/abstention claim. Do not hold the ungated
  comparisons open while awaiting references.
