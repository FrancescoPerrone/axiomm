# v0.1 acceptance criteria (confirmatory comparisons)

**Status:** draft for sign-off. **No threshold is locked.** Every `[SIGN-OFF]`
value must be fixed — and this file committed — **before** the held-out
confirmatory run. This document operationalises §4 of
`v0.1_external_validation_preregistration.md`.

## Preregistration discipline (pilot vs held-out)

- **Pilot/calibration set.** A clearly separated set of fixtures is used *only* to
  estimate realistic tolerances. Pilot results are **not** part of any confirmatory
  claim.
- **Lock, then confirm.** After tolerances are estimated on the pilot and signed
  off, they are frozen. The confirmatory comparison then runs **once** on a
  **held-out** evaluation set that was not used to set the thresholds.
- **Baseline tool versions** are recorded with the run (PyMca, HyperSpy, PyXRF),
  plus the exact AXIOMM commit under test.

## Field definitions

Each comparison specifies: **what is measured**, the **comparator/reference**, the
**error metric and denominator**, the **zero / near-zero treatment**, the
**threshold** (with status), the **justification**, and whether a failure is
**release-blocking (P0/P1)** or **diagnostic only**.

---

### C1 — Net line intensities on synthetic spectra

- **Measured:** AXIOMM per-line net integrated intensity vs PyMca fitted net peak
  area, on the *same* synthetic spectrum with a known line set.
- **Comparator:** PyMca peak fit (primary XRF comparator).
- **Metric (two regimes — relative % is not used near zero):**
  - *Above-floor* lines (true net above a window-specific floor
    `T = k·√(background counts in window)`, `k` `[SIGN-OFF]`): relative error
    `|A−P| / P`, denominator = the PyMca net `P`.
  - *Near-zero* lines (true net ≤ `T`): agreement in counting-uncertainty units,
    `|A−P| ≤ m·√(gross)` with `m` `[SIGN-OFF]`, **and** both estimates stay below
    `T` (neither invents a peak).
- **Zero/near-zero:** a line with no true signal must read ≈0 within counting
  noise on both sides; no relative-error division by ~0.
- **Threshold:** above-floor rel ≤ `[SIGN-OFF, pilot]` (candidate 10%); near-zero
  per the `m·√(gross)` rule. Well-separated lines only; overlaps are C2.
- **Justification:** well-separated lines on controlled spectra should agree up to
  the background-model difference; relative error is undefined at zero.
- **Blocking:** a reproducible **systematic bias** on above-floor lines → **P1**
  (biases every downstream wt%). Random scatter within tolerance → diagnostic.

### C2 — Behaviour under overlaps, missing lines, zero signal

- **Measured:** on designed cases — (a) two lines within the detector resolution,
  (b) a reference line with no signal, (c) a flat zero-signal window — whether
  AXIOMM flags the overlap, abstains / marks `measured_zero` / `not_measured`, and
  **never reports a net above floor where there is no peak**.
- **Comparator:** the known synthetic truth; PyMca for the overlap-resolved case.
- **Metric:** binary pass/fail per designed case (correct status + no fabricated
  signal). Not a numerical-agreement comparison.
- **Zero/near-zero:** this is the zero case; AXIOMM must report `measured_zero`,
  not an invented positive net.
- **Threshold:** 100% correct on the designed case set.
- **Justification:** the release claim is that AXIOMM *exposes* rather than
  conceals missing/insufficient evidence.
- **Blocking:** fabricating signal where none exists, or claiming resolution of an
  unresolvable overlap → **P1** (fabricates/suppresses evidence). Conservative
  abstention on a true overlap → acceptable.

### C3 — Single-energy cation ratios vs an independent Cliff–Lorimer

- **Measured:** named cation ratios (**Si-referenced**: Ca/Si, Fe/Si, Mg/Si, Al/Si
  — final list `[SIGN-OFF]`) from AXIOMM vs an independent Cliff–Lorimer
  computation (HyperSpy) using the **same k-factors, same reference element (Si),
  same net intensities**.
- **Comparator:** HyperSpy Cliff–Lorimer arithmetic (independent implementation of
  the *same* model).
- **Metric:** relative error per named ratio; denominator = the ratio value.
  Elements both `measured_positive` above floor only.
- **Zero/near-zero:** ratios involving a near-zero element are excluded (no ratio),
  not forced.
- **Threshold:** **tight** — same model, different code should agree to near
  numerical precision; candidate ≤ `[SIGN-OFF, pilot]` 1–2%. A larger gap is an
  arithmetic/implementation defect, not a model difference.
- **Justification:** this isolates AXIOMM's Cliff–Lorimer *arithmetic*; it is a
  code cross-check, not a physics comparison.
- **Blocking:** systematic ratio divergence beyond numerical noise → **P1**.
- **Companion (diagnostic only):** AXIOMM's uncorrected wt% vs PyMca's
  *matrix-corrected* quant will differ **systematically** by design — documented as
  the declared known difference, never a pass/fail.

### C4 — Map-level spatial agreement

- **Measured:** spatial overlap between AXIOMM phase/cluster domains and an
  **independent spatial phase reference** (imaging / EPMA map), after a declared
  clustering-label ↔ phase correspondence.
- **Comparator:** independent spatial reference. **STATUS: GATED — none currently
  available** (no sample imaged; A21-016 is not imaged — see §A21-016 below).
- **Metric:** **Dice** coefficient per phase domain (IoU reported alongside), after
  a fixed label correspondence (declared mapping or Hungarian assignment). Not a
  generic percentage.
- **Zero/near-zero:** n/a (spatial).
- **Threshold:** `[SIGN-OFF]` per sample, expert-set, estimated on a pilot region.
- **Justification:** demonstrates the "spectral map → spatial mineral
  interpretation" claim.
- **Blocking:** **diagnostic** by default (segmentation granularity differs from an
  annotation); **P1** only if domains are systematically mis-located so as to change
  the interpretation.

### C5 — Abstention & false-positive rates for mineral labels

- **Measured:** on a sample with a known assemblage (expert phase-reference):
  (a) **false-positive rate** = clusters confidently labelled a mineral *absent*
  from the known assemblage ÷ total labelled clusters; (b) abstention
  appropriateness = clusters abstaining where evidence is genuinely insufficient.
- **Comparator:** expert **phase-reference** (not "ground truth" unless backed by
  an independent method), with the supporting evidence recorded per phase
  (petrography / EPMA / prior EDS-XRF / sample preparation).
- **Metric:** FP rate with an explicit denominator (labelled clusters) and defined
  negatives (library minerals not in the assemblage). Kept **separate** from
  numerical agreement (C1/C3).
- **Zero/near-zero:** n/a.
- **Threshold:** FP rate ≤ `[SIGN-OFF]`; abstentions justified against the evidence.
- **Justification:** the release claim is abstention-capable and exposes
  insufficient evidence, so confident false positives must be rare.
- **Blocking:** confidently naming an absent mineral (high FP) → **P1**, *weighted
  by the expert-reference quality and the reference-circularity caveat*. Runs only
  on samples with an assemblage reference (not A21-016).

### C6 — Reproducibility (save/load + reruns)

- **Measured:** identity of results and provenance across save/load and fixed-seed
  reruns.
- **Comparator:** AXIOMM itself.
- **Metric:** exact equality (labels, scores, provenance) within float epsilon.
- **Threshold:** exact.
- **Blocking:** any non-reproducibility → **P1** (prevents reproduction).

### C7 — Runtime & memory

- **Measured:** wall-clock and peak RSS on representative datasets.
- **Comparator:** —.
- **Metric:** documented numbers.
- **Threshold:** documented, no pass/fail.
- **Blocking:** **diagnostic**, except out-of-memory / crash on the primary
  workflow → **P0**.

### C8 — Provenance completeness & correctness

- **Measured:** required provenance fields present and faithful after save/load
  (checklist: run config; per-element `source_energy_kev` + `reference_energy_kev`;
  `cross_energy_scale` / `cross_energy_status`; reliability `counting_basis`;
  policy name + version; software/reference versions; diagnostics).
- **Comparator:** the checklist.
- **Metric:** checklist complete **and** round-trip faithful.
- **Threshold:** complete.
- **Blocking:** missing provenance that prevents reproduction → **P1**; cosmetic
  gaps → diagnostic.
